# Mohammed Junaid Betgeri — CSE Portfolio

A mobile-first, high-performance personal portfolio showcasing full-stack development, data analytics, and cybersecurity projects.

## Tech Stack

- **Framework:** TanStack Start (React 19 & TypeScript)
- **Styling:** Tailwind CSS (v4), Vanilla CSS & OKLCH color spaces
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Build Tool:** Vite & Nitro

## Getting Started

### Prerequisites

Node.js (v20+ recommended) and npm.

### Installation

```bash
git clone <repository-url>
cd <repository-directory>
npm install
```

### Running Locally

```bash
npm run dev
```

### Building for Production

```bash
npm run build
```
